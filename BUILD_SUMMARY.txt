      [ERROR] fetch_channels: 400 Client Error: Bad Request
      → Bot crashes, needs manual restart

   ├─ fetch_channels():  3 retry attempts with 2-sec delay
   ├─ fetch_epg():       2 retry attempts with 1-sec delay
   ├─ refresh_token():   3 retry attempts with 2-sec delay
   ├─ Features Added:
   │  ✅ Auto-refresh token on 401/403 errors
   │  ✅ Cache fallback if all retries fail
   │  ✅ Exponential backoff between attempts
   │  ✅ Detailed error logging with attempt numbers
   └─ Result: ✅ Network failures no longer break the bot

3️⃣  IMPROVED: Token Refresh Logic
   ├─ Now updates both authToken AND ssoToken
   ├─ Better error messages
   ├─ Graceful failure (doesn't crash)
   └─ Result: ✅ More reliable token management
