## Usage Examples

### Search for a specific channel
```
/search star plus
→ Shows: Star Plus (400) and Star Plus HD (401)
```

### Get a channel by ID
```
/epg 816
→ Shows EPG for that channel ID
```

### Browse by genre
```
/channels → Click "⭐ Entertainment"
→ See all 9 entertainment channels
```

### Check catchup availability
```
/catchup 816
→ Shows if channel supports catchup
```
