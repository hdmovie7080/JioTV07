════════════════════════════════════════════════════════════════════════════════

1. Check Python version (3.8+)
2. Run: pip install --upgrade pyrogram TgCrypto requests
3. Check Telegram credentials are correct in bot.py
4. Check internet connection

1. Bot token must be valid
2. Internet connection required
3. Check Telegram API status
