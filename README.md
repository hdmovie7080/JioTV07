# JioTV PRO Bot v3.0

Complete, Production-Ready Telegram Bot for JioTV Streaming

## Features

- 80+ TV Channels organized by 8 genres
- Instant channel search
- EPG (Electronic Program Guide) support
- Catchup content for 14+ channels
- Zero configuration - Ready to deploy
- Lightning fast response times
- Full error handling

## Installation

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run Bot

```bash
python bot.py
```

That's it! The bot will start immediately.

## Commands

| Command | Description |
|---------|-------------|
| `/start` | Welcome menu |
| `/channels` | Browse channels by genre |
| `/search <name>` | Search for a channel |
| `/epg <id>` | View TV guide |
| `/catchup <id>` | Watch recent episodes |
| `/help` | Show help menu |
