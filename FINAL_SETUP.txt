STEP 1: Get Credentials
──────────────────────
1. Go to https://my.telegram.org
2. Login → API development tools
3. Fill form → Copy API_ID and API_HASH

4. Message @BotFather on Telegram
5. Send /newbot → Follow prompts
6. Copy BOT_TOKEN

7. Message @userinfobot
8. Copy your OWNER_ID (a number like 5009476236)

STEP 2: Create .env File
──────────────────────
Create file named ".env" with:

    API_ID=20093900
    API_HASH=314286d8af54eda517ff6f3974fd3aad
    BOT_TOKEN=YOUR_BOT_TOKEN_HERE
    OWNER_ID=5009476236

⚠️  Replace values with your own!

STEP 3: Install & Run
──────────────────────
    pip install -r requirements.txt
    python bot.py
