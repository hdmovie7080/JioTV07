================================================================================
                           THE PROBLEM
================================================================================

Every time users ran commands like /channels, /search, /list, the bot would
crash with this error:

    400 Client Error: Bad Request
    Error Message: "invalid channel_id: must be numeric"

The bot kept retrying 3 times, then giving up. All channel-related commands
were broken.

================================================================================
                         ROOT CAUSE IDENTIFIED
================================================================================

The bot was making this API request:

    https://jiotvapi.cdn.jio.com/apis/v1.3/getepg/get?offset=-1&channel_id=all

The JioTV API REJECTS channel_id=all and ONLY accepts numeric channel IDs
(like 816, 500, etc.)

Evidence from your test logs:
✅ Channel 816 request → 200 OK (works)
❌ channel_id=all request → 400 Bad Request (fails)

================================================================================
                            THE SOLUTION
================================================================================

1. ADDED: VALID_CHANNELS dictionary with 50+ channel IDs
2. CHANGED: fetch_channels() to load from dictionary instead of API
3. RESULT: Instant response, no more 400 errors

File Changes:
  • bot.py - Added 43-line VALID_CHANNELS dict + rewrote fetch_channels()
  • test_api.py - Updated test to use valid channels
